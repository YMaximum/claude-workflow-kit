# Glossary (plain words)

Use these one-line explanations the first time a term comes up with a user who may
not know it. Do not lecture; one line, then continue.

| Term | Plain meaning |
|---|---|
| **grill** | Claude asks you questions one at a time, each with a suggested answer, until everything about a decision is clear. |
| **spec** | A short written description of what we will build and how we know it is done. |
| **ticket** | One small piece of work, written down so anyone (or any session) can pick it up. |
| **acceptance criteria** | The checklist that says when a ticket is done. |
| **vertical slice / demoable** | A ticket that delivers something you can actually see or try, not just one layer of code. |
| **repo** | The project folder that git keeps history for. |
| **commit** | A saved snapshot of changes, with a message saying why. |
| **branch** | A separate line of work, so unfinished changes don't affect the main version. |
| **push** | Upload your commits to GitHub (or another server). |
| **PR (pull request)** | A request to merge a branch, where changes are reviewed first. |
| **merge** | Bring a branch's changes into the main version. |
| **test** | A small program that checks the code does what it should. |
| **test first / failing test** | Write the check before the code; seeing it fail first proves the check really tests something. |
| **lint** | An automatic check for code style and common mistakes. |
| **build** | Turning the source code into the version that runs (e.g. in a browser). |
| **plan mode** | A Claude Code mode (Shift+Tab) where Claude can read and ask but cannot change files. |
| **subagent** | A helper Claude that does one focused job (like searching) and reports back. |
| **handover** | Claude writes down where the work stands, so a new session can continue. |
| **`/clear`** | Start a fresh conversation. Long chats get slower and cost more; `HANDOVER.md` carries what matters. |
| **MCP / connector** | A plug-in that lets Claude talk to another tool, such as Jira. |
| **CLI** | A program you run by typing commands, like `git` or `gh`. |
